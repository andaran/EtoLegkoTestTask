# Speed test

Установите зависимости командой `uv sync` и запустите `uv run python main.py`.
По умолчанию используется URL из `config.toml`. Его можно изменить в файле или
переопределить для одного запуска: `uv run python main.py --url https://example.com/image.jpg`.

В конфигурации указано [изображение Unsplash](https://images.unsplash.com/photo-1500530855697-b586d89ba3ee?fm=png)
размером около 15,9 МБ. Количество запросов задаётся параметром `request_count`
в `config.toml`: по умолчанию 10 запросов, всего около 159 МБ.

Итоговая скорость выводится в МиБ/с (1 МиБ = 1 048 576 байт) и Мбит/с
(1 Мбит = 1 000 000 бит). Она равна общему объёму, делённому на сумму
времени запросов. Среднее время запроса выводится в секундах.
